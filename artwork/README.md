# Pack icon source

`pack-icon-source.png` is the user-supplied **Minecraft Transit Railway RAM Upgrade.png**,
preserved byte-for-byte at its original 1254 × 1254 RGB PNG dimensions.

Source SHA-256: `627300a098c12f4deee3c803e91ce4a10eeaacfe58f550572f84ca9a56492f0b`.

Run `tools/render_pack_icon.py` with the optional Pillow artwork dependency to
generate `src/main/resources/pack.png`. The default conversion preserves the full
square composition, converts to RGBA and resizes to 512 × 512 with Lanczos sampling.
`--source`, `--size` and `--output` can select alternate inputs and preview outputs.
